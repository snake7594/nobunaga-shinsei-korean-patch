# 참고 자료 (번역 검수용) — 파일 자체는 저장소에 없습니다

번역 품질 검수에 참고한 **제3자 자료**입니다. 저작권이 각 작성자에게 있어 이 저장소에는
**넣지 않습니다.** 검수에 쓴 방법과 결과만 공개합니다.

| 파일(로컬) | 내용 | 출처 |
|---|---|---|
| `신생_이벤트_원문대조번역.xlsx` | 역사 이벤트 대사의 일본어 원문(게임 화면 OCR) ↔ 한국어 번역, 7,450행 | 커뮤니티 번역 |
| `신생_공략집_v1.1.7.pdf` | 게임 시스템 공략(내정 수식·시설·정책·합전 등) 68쪽 | nobunaga-shinsei-wiki.com, cafe.naver.com/koei21 (문서 1쪽에 출처 명기) |

검수 결과 자체는 저장소에 있습니다 — `data/fixes/text_fixes.json` 의 치환 규칙과
커밋 메시지에 무엇을 왜 고쳤는지 남겨 두었습니다.

## 같은 방식으로 검수하려면

엑셀 파일을 구해 이 폴더에 두고(또는 `--xlsx` 로 경로 지정) 아래를 실행합니다.

```bash
python tools/match_reference.py \
  --xlsx <엑셀 경로> \
  --jp "<...>/Program 1/romfs/MSG_PK/JP" --data data/ko/puk_117 \
  --jp2 "<...>/base_v0_out/MSG/JP"        --data2 data/ko/base \
  --out reference_match.json
```

엑셀 쪽 원문은 OCR이라 오탈자가 있어(`てある`↔`である`, `リ`↔`り`, `隹`↔`誰` …) 글자
그대로는 게임 텍스트와 맞지 않습니다. 그래서 **한자만 뽑아 3-gram으로 후보를 좁힌 뒤
유사도로 확정**합니다. 1.1.7 기준 5,746건이 매칭됐습니다.

## 표기 원칙 — 참고본과 다릅니다

참고 번역은 문장이 자연스럽지만 고유명사를 **통용 표기**로 적습니다. 이 패치는
**국립국어원 일본어 표기법**을 따르므로 표기는 우리 것을 유지하고 **문장 표현만** 참고했습니다.
