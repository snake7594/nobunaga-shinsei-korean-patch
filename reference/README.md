# 참고 자료 (번역 검수용)

번역 품질 검수에 참고한 외부 자료입니다. **패치에 그대로 들어가지 않으며**, 표현을
다듬을 때 대조용으로만 씁니다.

| 파일 | 내용 | 출처 |
|---|---|---|
| `신생_이벤트_원문대조번역.xlsx` | 역사 이벤트 대사의 일본어 원문(게임 화면 OCR) ↔ 한국어 번역, 7,450행 | 커뮤니티 번역 |
| `신생_공략집_v1.1.7.pdf` | 게임 시스템 공략 (내정 수식·시설·정책·합전 등) 68쪽 | nobunaga-shinsei-wiki.com, cafe.naver.com/koei21 (문서 1쪽에 출처 명기) |

## 쓰는 방법

`tools/match_reference.py` 가 엑셀의 일본어 원문을 게임 원문과 대조합니다. 엑셀 쪽 원문은
OCR이라 오탈자가 있어(`てある`↔`である`, `リ`↔`り`, `隹`↔`誰` …) 글자 그대로는 맞지
않습니다. 그래서 **한자만 뽑아 3-gram으로 후보를 좁힌 뒤 유사도로 확정**합니다.

```bash
python tools/match_reference.py \
  --jp "<...>/Program 1/romfs/MSG_PK/JP" --data data/ko/puk_117 \
  --jp2 "<...>/base_v0_out/MSG/JP"        --data2 data/ko/base \
  --out reference_match.json
```

## 표기 원칙 — 참고본과 다릅니다

참고 번역은 문장이 자연스럽지만 고유명사를 **통용 표기**로 적습니다. 이 패치는
**국립국어원 일본어 표기법**을 따르므로 표기는 우리 것을 유지하고 **문장 표현만** 참고합니다.

## 저작권

두 자료 모두 제3자가 만든 것으로, 저작권은 각 작성자에게 있습니다. 검수 목적의 참고용으로
보관하고 있으며, 권리자의 요청이 있으면 즉시 내리겠습니다.
