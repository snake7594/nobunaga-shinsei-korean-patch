# 노부나가의 야망 신생 한글 패치 (비공식) — 설치 안내

Switch용 **노부나가의 야망 신생(信長の野望・新生)** 일본판의 비공식 한글 패치입니다.

> ⚠️ **받은 zip과 게임 버전이 일치해야 합니다.**
> 파일명의 버전(1.1.7 / 1.1.5 / 1.1.4)을 본인 게임 버전과 맞추세요. 특히
> `exefs/main`(실행파일)은 버전 전용이라 다른 버전에 얹으면 부팅에 문제가 생길 수 있습니다.

## 설치 (클린 설치 권장)

**실기 (Atmosphère)**

1. SD카드의 기존 한글패치 폴더를 **모두 삭제**합니다.
   `sd:/atmosphere/contents/` 안의 `01007ab012872000`, `01007ab012872001`,
   `01007ab0128730xx` (추가 시나리오 DLC용)
2. zip 속 **`atmosphere` 폴더를 SD카드 루트에 통째로 복사**합니다(병합).
3. 게임을 실행합니다.

**에뮬레이터 (Ryujinx / Yuzu)**

- 게임 우클릭 → *Open Mods Directory*(또는 *Open Mod Data Location*) 아래에
  타이틀 ID 폴더를 만들고, zip 속 `atmosphere/contents/<타이틀 ID>/` 안의
  `romfs`·`exefs`를 그대로 넣습니다.

## 폴더 구성

```
atmosphere/contents/
  01007ab012872000/     ← 일반 게임 프로그램
    exefs/main            한글 시스템 메시지
    romfs/MSG/JP/         한글 텍스트
    romfs/RES_JP/         한글 폰트 + 이미지
  01007ab012872001/     ← 파워업키트 프로그램 (PUK판만)
    exefs/main            한글 시스템 메시지 (1.1.7은 한국어 입력기 포함)
    romfs/MSG_PK/JP/      파워업키트 한글 텍스트
    romfs/RES_JP_PK/      파워업키트 한글 폰트 + 이미지
  01007ab0128730xx/     ← 추가 시나리오 DLC (해당 DLC 보유 시)
```

## 문제가 생기면

- **게임이 부팅되지 않음** → 해당 프로그램 폴더의 `exefs` 폴더만 삭제하세요.
  텍스트·폰트·이미지 한글화는 그대로 동작합니다.
  (단, 1.1.7의 **한국어 입력기**는 `exefs`에 들어 있어 함께 빠집니다.)
- **일부가 일본어로 보임** → 구버전 패치가 남아 있을 수 있습니다. 위 폴더들을 지우고
  다시 복사하세요(클린 설치).

## 알려진 사항

- 크레딧(스태프 이름)과 시나리오 검색용 내부 인덱스 문자열은 원문(일본어)으로 남습니다.
- 폰트는 서울한강체(서울시 배포 무료 글꼴)라 원본 붓글씨체와 스타일이 다를 수 있습니다.
- 인명·지명은 국립국어원 일본어 표기법을 따릅니다.
- 기계 번역이 포함되어 일부 문장은 어색하거나 오역이 있을 수 있습니다.
